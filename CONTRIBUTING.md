# Como Contribuir

Obrigado pelo interesse em contribuir com o FuelTech FT700! Toda ajuda é bem-vinda.

---

## Reportando Bugs

1. Acesse a aba **Issues** do repositório
2. Clique em **New Issue**
3. Descreva o problema com o máximo de detalhes possível:
   - O que aconteceu?
   - O que era esperado?
   - Como reproduzir o erro?
   - Versão do QBCore e do FiveM

---

## Sugerindo Melhorias

Tem uma ideia legal? Abre uma **Issue** com o título começando em `[SUGESTÃO]` e descreve o que você gostaria de ver no projeto.

---

## Enviando Código (Pull Request)

1. **Fork** o repositório clicando em "Fork" no canto superior direito do GitHub
2. Clone o fork na sua máquina:
   ```
   git clone https://github.com/SEU_USUARIO/Fueltech700_GTARP_QBCore
   ```
3. Crie uma branch para sua alteração:
   ```
   git checkout -b minha-melhoria
   ```
4. Faça suas alterações e commit:
   ```
   git add .
   git commit -m "feat: descrição da melhoria"
   ```
5. Envie para o seu fork:
   ```
   git push origin minha-melhoria
   ```
6. Abra um **Pull Request** no repositório original explicando o que foi alterado
